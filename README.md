# DSH para iPhone

App nativo de iPhone para conversar com o DSH que roda neste notebook e com a API da DeepSeek,
com histórico local, artefatos interativos, voz, ferramentas e integração com Atalhos e widget.

- Contrato técnico do time: [docs/CONTRATO-SWIFT.md](docs/CONTRATO-SWIFT.md)
- Entrega e instalação: docs/ENTREGA.md (escrito depois do primeiro build verde)

O projeto Xcode nasce do `project.yml` (XcodeGen). Sem ele, o repositório é só fonte.
